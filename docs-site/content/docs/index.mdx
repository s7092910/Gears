Gears is a mod settings framework for 7 Days to Die. It gives a mod a settings page in the game's
Mods menu, remembers what the player chose, syncs per-world settings from the server to every
client, and lets both XML patches and C# code read those values.

<Callout type="warn" title="Upgrading from an older Gears?">
  This documentation replaces the older wiki, which described GearsAPI 2.x and the V1
  `ModSettings.xml` schema. Neither loads any more. If you have a mod built on either, start with
  [Upgrading to GearsAPI 3](/docs/upgrading-to-gearsapi-3).
</Callout>

| Component | Version |
|---|---|
| Gears (the mod players install) | 8.0.0 |
| GearsAPI.dll (the assembly mods reference) | 3.0.0 |

## Two ways to use Gears

<Tabs items={['XML only', 'XML plus C#']}>
  <Tab value="XML only">
    Drop a `ModSettings.xml` next to your `ModInfo.xml` and Gears builds the settings page for you.
    Read the values from your `Config/*.xml` patches with the `modsetting()` function. No C#, no
    reference to any Gears assembly, and your mod keeps working if Gears is not installed (the
    settings page and the patches that use it just do not appear).
  </Tab>
  <Tab value="XML plus C#">
    Reference `GearsAPI.dll`, implement one interface, and Gears hands your code the typed settings
    at startup and whenever the player applies a change. You can also create settings from code
    instead of XML.
  </Tab>
</Tabs>

## What Gears reads from your mod folder

| File | Purpose |
|---|---|
| `ModInfo.xml` | The game's own manifest. Gears uses `<Name>` as your mod's identity everywhere, and reads the optional `<Icon>` and `<Banner>` for the Mods menu. |
| `ModSettings.xml` | Your settings, in the mod root next to `ModInfo.xml`. |
| `Config/Localization.csv` | The game's localization file; every display key you use in `ModSettings.xml` needs a row here. |

Gears writes two files of its own, which you never author by hand: the player's saved global
values under the game's user data folder (`Gears\ModSettings.xml`), and each save's
`WorldModSettings.xml` in the save folder.
