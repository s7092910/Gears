```csharp
[AttributeUsage(AttributeTargets.Class, Inherited = false)]
public sealed class SettingsSerializationProvider : Attribute
```

Marks a class as holding [[`SettingParserAttribute`](/docs/reference/attributes/setting-parser-attribute)] and [[`SettingFormatterAttribute`](/docs/reference/attributes/setting-formatter-attribute)] methods. Gears scans every loaded assembly for classes with this attribute at `GameAwake`. The class name has no `Attribute` suffix; write `[SettingsSerializationProvider]`. See C# Custom Value Types.

**Inheritance:** `Object` → `Attribute` → `SettingsSerializationProvider`\
**Attributes:** `AttributeUsageAttribute`
