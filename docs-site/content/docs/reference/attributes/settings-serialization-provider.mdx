Marks a class as holding [`[SettingParser]`](/docs/reference/attributes/setting-parser-attribute) and
[`[SettingFormatter]`](/docs/reference/attributes/setting-formatter-attribute) methods. Gears scans every loaded
assembly for classes with this attribute at `GameAwake`. The class name has no `Attribute`
suffix; write `[SettingsSerializationProvider]`. See
[C# Custom Value Types](/docs/csharp/custom-value-types).

**Inheritance:** `Object` → `Attribute` → `SettingsSerializationProvider`\
**Attributes:** `AttributeUsageAttribute`
