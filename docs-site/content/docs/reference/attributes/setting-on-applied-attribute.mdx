```csharp
public sealed class SettingOnAppliedAttribute : SettingListenerAttribute
```

Binds a static method to the named setting's `OnSettingApplied` event
([`IGlobalModSetting`](/docs/reference/global/i-global-mod-setting)), which fires when the setting is applied. Global settings only,
including Color and Binding. Required method signature: `static void M(IGlobalModSetting setting)`.

**Inheritance:** `Object` → `Attribute` → [`SettingPathAttribute`](/docs/reference/attributes/setting-path-attribute) → [`SettingListenerAttribute`](/docs/reference/attributes/setting-listener-attribute) → `SettingOnAppliedAttribute`
