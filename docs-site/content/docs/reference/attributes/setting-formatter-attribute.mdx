```csharp
[AttributeUsage(AttributeTargets.Method, AllowMultiple = false)]
public sealed class SettingFormatterAttribute : Attribute
```

Marks a static method inside a [[`SettingsSerializationProvider`](/docs/reference/attributes/settings-serialization-provider)] class as the formatter for a value type. The method must have the signature `static string Method(T value, string format)`, where `format` is the setting's UI or serialization formatter string and may be `null`; a mismatch throws `InvalidOperationException` when Gears scans it.

**Inheritance:** `Object` → `Attribute` → `SettingFormatterAttribute`\
**Attributes:** `AttributeUsageAttribute`
