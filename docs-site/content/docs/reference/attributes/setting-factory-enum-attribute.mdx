```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class SettingFactoryEnumAttribute : Attribute
```

Registers an open generic class with one type parameter as the implementation of a setting family for every enum.

**Inheritance:** `Object` → `Attribute` → `SettingFactoryEnumAttribute`\
**Attributes:** `AttributeUsageAttribute`

<Callout type="warn" title="Reserved">
  Gears scans only its own assembly for this attribute, so it has no effect in a mod
  assembly.
</Callout>
