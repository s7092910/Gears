---
title: "SettingAttribute"
description: "Binds a static field or property to the setting its path names. Pass the declaring type to BindSettingsClass and the member is assigned the resolved setting. A field must be static and neither readonly nor const; a property must be static and have a setter, which may be private."
---

<TypeMeta kind="Sealed class" namespace="GearsAPI.Attributes" source="GearsAPI/Source/Attributes/Settings/SettingAttribute.cs" />

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false, Inherited = false)]
public sealed class SettingAttribute : SettingPathAttribute
```

`BindSettingsClass` assigns the resolved setting into the member before it subscribes any listener on the same type. The member's declared type must be one the setting actually implements — anything from [`IModSetting`](/docs/reference/settings/i-mod-setting) down to the concrete class. Anything else is logged and skipped. See the Bind Settings with Attributes guide.

**Inheritance:** `Object` → `Attribute` → [`SettingPathAttribute`](/docs/reference/attributes/setting-path-attribute) → `SettingAttribute`\
**Attributes:** `AttributeUsageAttribute`
