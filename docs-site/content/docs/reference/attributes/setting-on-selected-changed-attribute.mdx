```csharp
public sealed class SettingOnSelectedChangedAttribute : SettingListenerAttribute
```

Binds a static method to the named setting's `OnSelectedChanged` event ([`IValueModSetting<T>`](/docs/reference/settings/i-value-mod-setting)), which fires when the value selected in the UI changes. Global and world value settings. Required method signature: `static void M(IValueModSetting<T> setting, T newValue)`. Pass `includeInSync: true` to have `SyncSettingsToClass` call the method with the setting's current `SelectedValue`.

**Inheritance:** `Object` → `Attribute` → [`SettingPathAttribute`](/docs/reference/attributes/setting-path-attribute) → [`SettingListenerAttribute`](/docs/reference/attributes/setting-listener-attribute) → `SettingOnSelectedChangedAttribute`

## Constructors

### SettingOnSelectedChangedAttribute(String, Boolean)

```csharp
public SettingOnSelectedChangedAttribute(string settingPath, bool includeInSync = false)
```

Initializes the attribute with the setting path, and optionally opts the listener in to `SyncSettingsToClass`.

## Properties

### IncludeInSync

```csharp
public bool IncludeInSync { get; }
```

Gets whether `SyncSettingsToClass` calls this listener with the setting's current `SelectedValue`. Defaults to `false`, which leaves the listener running only when its event fires.
