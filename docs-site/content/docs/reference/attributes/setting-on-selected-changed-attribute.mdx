```csharp
public sealed class SettingOnSelectedChangedAttribute : SettingListenerAttribute
```

Binds a static method to the named setting's `OnSelectedChanged` event ([`IValueModSetting<T>`](/docs/reference/settings/i-value-mod-setting)), which fires when the value selected in the UI changes. Global and world value settings. Required method signature: `static void M(IValueModSetting<T> setting, T newValue)`. Pass `invokeOnBind: true` to also call the method once with the setting's current `SelectedValue` as soon as `BindSettingsClass` has bound every listener on the type.

**Inheritance:** `Object` → `Attribute` → [`SettingPathAttribute`](/docs/reference/attributes/setting-path-attribute) → [`SettingListenerAttribute`](/docs/reference/attributes/setting-listener-attribute) → `SettingOnSelectedChangedAttribute`

```csharp
public SettingOnSelectedChangedAttribute(string settingPath, bool invokeOnBind = false)
```

## Properties

### InvokeOnBind

```csharp
public bool InvokeOnBind { get; }
```

Gets whether the listener is invoked once with the setting's current `SelectedValue` after `BindSettingsClass` has bound every listener on the type. Defaults to `false`.
