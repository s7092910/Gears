```csharp
[AttributeUsage(AttributeTargets.Method, AllowMultiple = true)]
public abstract class SettingListenerAttribute : SettingPathAttribute
```

Base class of the four attributes that bind a static method to a setting's event through
`BindSettingsClass`. Cannot be applied directly.

**Inheritance:** `Object` → `Attribute` → [`SettingPathAttribute`](/docs/reference/attributes/setting-path-attribute) → `SettingListenerAttribute`\
**Derived:** [`SettingOnValueChangedAttribute`](/docs/reference/attributes/setting-on-value-changed-attribute) · [`SettingOnAppliedAttribute`](/docs/reference/attributes/setting-on-applied-attribute) · [`SettingOnSelectedChangedAttribute`](/docs/reference/attributes/setting-on-selected-changed-attribute) · [`SettingOnEnabledAttribute`](/docs/reference/attributes/setting-on-enabled-attribute)\
