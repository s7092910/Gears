```csharp
[AttributeUsage(AttributeTargets.Method, AllowMultiple = true)]
public abstract class SettingListenerAttribute : SettingPathAttribute
```

Base for attributes that bind a static method to a setting's event. The setting path must be in the form "tabName.CategoryName.SettingName" for global settings and "CategoryName.SettingName" for world settings.
