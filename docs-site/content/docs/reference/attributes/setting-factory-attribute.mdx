```csharp
[AttributeUsage(AttributeTargets.Method | AttributeTargets.Class, AllowMultiple = false)]
public sealed class SettingFactoryAttribute : Attribute
```

Registers a class as the implementation of a setting family for one value type, for example
`[SettingFactory(typeof(ISelectorGlobalSetting<>), typeof(int))]`.

**Inheritance:** `Object` → `Attribute` → `SettingFactoryAttribute`\
**Attributes:** `AttributeUsageAttribute`

<Callout type="warn" title="Reserved">
  Gears scans only its own assembly for this attribute, so it has no effect in a mod
  assembly.
</Callout>
