A world two-position setting. Implemented for `bool`, `string` and any enum, with the same side
defaults as the global version.

**Type parameters:** `T` — `bool`, `string` or an enum.\
**Implements:** [`IWorldModSetting`](/docs/reference/world/i-world-mod-setting) · [`IValueModSetting<T>`](/docs/reference/settings/i-value-mod-setting) · [`ISwitchSettingBase`](/docs/reference/base/i-switch-setting-base) · [`IValueModSettingBase`](/docs/reference/base/i-value-mod-setting-base) · [`IModSetting`](/docs/reference/settings/i-mod-setting)
