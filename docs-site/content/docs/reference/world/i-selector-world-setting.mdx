```csharp
public interface ISelectorWorldSetting<T> : IWorldModSetting, IValueModSetting<T>, ISelectorSettingBase
```

A world setting chosen from a list of allowed values. Implemented for `int`, `float`, `string` and any enum. Raises `OnSelectedChanged` only; there is no `OnValueChanged` on world settings.

**Type parameters:** `T` — `int`, `float`, `string` or an enum.\
**Implements:** [`IWorldModSetting`](/docs/reference/world/i-world-mod-setting) · [`IValueModSetting<T>`](/docs/reference/settings/i-value-mod-setting) · [`ISelectorSettingBase`](/docs/reference/base/i-selector-setting-base) · [`IModSetting`](/docs/reference/settings/i-mod-setting) · [`IValueModSettingBase`](/docs/reference/base/i-value-mod-setting-base)

## Methods

### SetAllowedValues(T[])

```csharp
void SetAllowedValues(T[] values);
```

Replaces the allowed values with `values`, in that order.

### SetAllowedValues(T, T, T)

```csharp
void SetAllowedValues(T increment, T min, T max);
```

Replaces the allowed values with the range `min` to `max` in steps of `increment`. Same validation as the global version.

### GetAllowedValues()

```csharp
T[] GetAllowedValues();
```

The values themselves, in the order they are selected through. The matching entry in [`ISelectorSettingBase.GetAllowedValuesDisplay`](/docs/reference/base/i-selector-setting-base) is how each one is rendered.
