public sealed class SharedSetting

A code holds only a hash of each setting's address. To encode, set the names and the hash is worked out from them. A decoded setting has only `Hash`, with every name left `null`; whoever knows the mod can match it with [`ShareCodeFormat.SettingHash`](/docs/reference/gearssharing/share-code-format).

**Inheritance:** `Object` → `SharedSetting`

### SharedSetting(String, SharedValue)

```csharp
public SharedSetting(string name, SharedValue value)
```

Creates a World setting entry. World setting names are unique within a mod, so no tab or category is stored.

### SharedSetting(UInt32, SharedValue)

```csharp
public SharedSetting(uint hash, SharedValue value)
```

Creates an entry for a setting known only by the hash of its address.
