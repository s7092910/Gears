```csharp
public interface IGlobalModSetting : IModSetting
```

A setting that belongs to the player rather than to a world: it knows its tab and category, can
warn about a reload or restart, and raises `OnSettingApplied` when applied.

**Implements:** [`IModSetting`](/docs/reference/settings/i-mod-setting)\
**Derived:** [`IGlobalModSettingsCategory`](/docs/reference/global/i-global-mod-settings-category) · [`IControlBindingSetting`](/docs/reference/global/i-control-binding-setting) · [`IGlobalValueSetting<T>`](/docs/reference/global/i-global-value-setting)

## Properties

### RestartScope

```csharp
SettingRestartScope RestartScope { get; set; }
```

Gets or sets what a change costs the player, as a [`SettingRestartScope`](/docs/reference/settings/setting-restart-scope): `None`, `Reload` or `Restart`. Always `None` on a category.

### Category

```csharp
IGlobalModSettingsCategory Category { get; }
```

Gets the [`IGlobalModSettingsCategory`](/docs/reference/global/i-global-mod-settings-category) this setting belongs to.

### Tab

```csharp
IGlobalModSettingsTab Tab { get; }
```

Gets the [`IGlobalModSettingsTab`](/docs/reference/global/i-global-mod-settings-tab) this setting belongs to.

## Events

### OnSettingApplied

```csharp
event OnSettingAppliedEvent OnSettingApplied;
```

Occurs when `ApplyCurrentChange()` runs, whether or not the value differs. Type [`OnSettingAppliedEvent`](/docs/reference/global/on-setting-applied-event).
