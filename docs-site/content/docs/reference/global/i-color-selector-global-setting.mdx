```csharp
public interface IColorSelectorGlobalSetting : IGlobalValueSetting<Color>
```

A global colour picker. Adds no members of its own; everything comes from
[`IGlobalValueSetting<T>`](/docs/reference/global/i-global-value-setting) with `T` = `UnityEngine.Color`. Serialized as `R,G,B` in 0–255.
Only the setting's own preview image is shown.
