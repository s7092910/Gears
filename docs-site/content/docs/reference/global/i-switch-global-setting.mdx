```csharp
public interface ISwitchGlobalSetting<T> : IGlobalValueSetting<T>, ISwitchSettingBase
```

A global two-position setting. Implemented for `bool` (left `false`, right `true`), `string` (no sides until `SetSwitchValues`) and any enum (left and right are the first two declared members).

**Type parameters:** `T` — `bool`, `string` or an enum.\
**Implements:** [`IGlobalValueSetting<T>`](/docs/reference/global/i-global-value-setting) · [`ISwitchSettingBase`](/docs/reference/base/i-switch-setting-base) · [`IGlobalModSetting`](/docs/reference/global/i-global-mod-setting) · [`IValueModSetting<T>`](/docs/reference/settings/i-value-mod-setting) · [`IValueModSettingBase`](/docs/reference/base/i-value-mod-setting-base) · [`IModSetting`](/docs/reference/settings/i-mod-setting)
