The non-generic members of a Switch: the two buttons, their text, and which one is lit.

**Implements:** [`IValueModSettingBase`](/docs/reference/base/i-value-mod-setting-base) · [`IModSetting`](/docs/reference/settings/i-mod-setting)\

## Properties

### LocalizationPrefix

```csharp
string LocalizationPrefix { get; set; }
```

Gets or sets the text prepended to each side's formatted value, with no separator, before it is looked up as a localization key.

## Methods

### GetRightText()

```csharp
string GetRightText();
```

Returns the localized text for the right value.

### GetLeftText()

```csharp
string GetLeftText();
```

Returns the localized text for the left value.

### SelectButton(SelectedButton)

```csharp
void SelectButton(SelectedButton button);
```

Sets the selected value to the value on that side.

### GetSelectedButton()

```csharp
SelectedButton GetSelectedButton();
```

Returns [`SelectedButton`](/docs/reference/base/i-switch-setting-base-selected-button)`.Right` when the selected value equals the right value and not the left value; otherwise `Left`. Derived from the value on every call.
