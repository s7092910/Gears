Gears is a mod settings framework for 7 Days to Die. These pages are for players and server admins
who installed a mod that uses Gears. If you are building a mod, read the
[Gears Documentation](/docs) instead.

With Gears installed, you can:

- Change a mod's settings from the **Mods** button on the main menu or the in-game menu.
- Pick a world's settings on the New Game and Continue Game screens.
- Keep your settings between game sessions, and when Gears or a mod updates.
- Set a dedicated server's settings in a file.

Gears adds no items, blocks or gameplay of its own. Every setting you see belongs to the mod that
declared it.

| Component | Version |
|---|---|
| Gears | 8.0.0 |

## Terms these pages use

A **mod setting** is one of a mod's options that Gears shows and saves. Mod settings come in two
kinds, and the difference decides who can change it and where.

| Term | Meaning |
|---|---|
| **global setting** | Yours. You change it from the main menu or the in-game menu, and the value applies in every world. |
| **world setting** | The world's. Whoever starts the world picks it, everyone in the world plays with the same value, and it cannot be changed while the world is running. |

## Get help

A problem with one mod's settings is usually that mod's to fix, so report it to the mod's author.
The [Player FAQ](/docs/players/faq) says how to tell the difference.

When the problem is with Gears itself, ask in the `#laydors-toolshed` channel on
[Guppy's Unofficial 7DtD Modding Server](https://discord.gg/eS73U4RxVj), a community Discord for 7
Days to Die modding, or open an issue on [GitHub](https://github.com/s7092910/Gears/issues). Include
your game version, your Gears version, and the full log file from the session where the problem
happened. The [Player FAQ](/docs/players/faq#where-is-the-log) says where to find the log.
