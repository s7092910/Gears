Install Gears, then change a mod's settings from the game's menus instead of editing files in its
folder.

## Install Gears

1. Download Gears from the [Gears page on Nexus Mods](https://www.nexusmods.com/7daystodie/mods/4017)
   and unzip it.
2. Put the `00000-Gears` folder in your **Mods** folder, beside the mods that need it. On Windows
   that is `%APPDATA%\7DaysToDie\Mods`; the game also reads a `Mods` folder next to the game's own
   executable.
3. Start the game with EasyAntiCheat turned **off**. Gears ships a `.dll`, and the game only loads
   code mods with EAC off.

Every player in a multiplayer game needs Gears and the mods that use it, and so does the server.

You know it worked when a **Mods** button appears on the main menu.

## Update Gears

1. Close the game.
2. Delete the old `00000-Gears` folder from your **Mods** folder.
3. Put the new `00000-Gears` folder in its place.

Your settings are not stored in the mod folder, so replacing it keeps them. Update the server and
every player at the same time, so everyone runs the same version.

The installed version is the `Version` value in `00000-Gears\ModInfo.xml`.

## Change a mod's settings

Mod settings come in two kinds, and each is changed in its own place.

| Kind | Who changes it | Where |
|---|---|---|
| **Global setting** — yours, and it applies in every world | you | the **Mods** button, from the main menu or while playing |
| **World setting** — the world's, and everyone in it plays with the same value | whoever starts the world | **Mods World Settings**, on the **Mods** tab of the New Game and Continue Game screens |

### Global settings, in the Mods menu

Open **Mods**, pick a mod from the list, and open its **Settings** tab. Change the rows you want,
then press **APPLY**. **DEFAULTS** puts every row on the page back to what the mod shipped with, and
**BACK** leaves without saving.

![The Mods menu with a mod selected, showing the rows of its settings](/images/Mods-Menu.png)

A mod can mark a setting as needing a world reload or a full game restart. Gears tells you when you
change one; the mod decides what actually happens until then.

### World settings, before the world starts

On the New Game or Continue Game screen, open the **Mods** tab, after **Multiplayer**, and press
**Mods World Settings**. On the New Game screen this picks the values a new world starts with. On
the Continue Game screen it changes them for a world you already have. Press **SAVE** when you are
done.

A new world starts with every mod's default values. If you changed them on the New Game screen
before, it starts with the values you picked there last.

![A mod's world settings category on the Mods World Settings screen](/images/World-Settings.png)

World settings cannot be changed while the world is running. Leave the world, change them on the
Continue Game screen, and start it again.

In multiplayer, the host's world settings are the ones everyone plays with. Your own copy of those
values is replaced by the server's when you join. Your global settings are untouched — they stay
yours on every server.

On a server you rent or run yourself, there is no menu to press. See
[World Settings on a Dedicated Server](/docs/players/dedicated-server-world-settings) and
[Global Settings on a Dedicated Server](/docs/players/dedicated-server-global-settings).

## Where your settings are saved

| What | File |
|---|---|
| Your global settings, for every mod at once | `%APPDATA%\7DaysToDie\Gears\ModSettings.xml` |
| One world's settings | `WorldModSettings.xml`, in that world's save folder |
| The values a new world will start with | `newGameWorldModSettings.xml`, beside your saves |

These are the Windows paths. `%APPDATA%\7DaysToDie` is the game's user data folder. On Linux it is
`~/.local/share/7DaysToDie`, and on macOS it is `~/Library/Application Support/7DaysToDie`. The
`Gears` folder and your saves sit inside it in the same places.

Gears writes all three. You never have to edit them by hand to play, and the in-game menus are the
supported way to change them.

<Callout type="warn" title="A renamed setting loses its saved value">
  Gears rewrites the global settings file at every startup. If a mod update renames one of its
  settings, the value saved under the old name is dropped and cannot be recovered. Note anything you
  would not want to set up again.
</Callout>

Removing a mod does not lose its values. Its entry stays in the file, and the values come back if you
install the mod again.
