Global settings belong to the player and apply to every world. In C# they are reached through
[`IModGlobalSettings`](/docs/reference/global/i-mod-global-settings), handed to
`OnGlobalSettingsLoaded` or available as `IGearsMod.GlobalSettings`. Namespaces:
`GearsAPI.Settings`, `GearsAPI.Settings.Global`, `GearsAPI.Settings.Base`.

## The tree

```text
IModGlobalSettings
└── IGlobalModSettingsTab            (GetTab / CreateTab / GetOrCreateTab)
    └── IGlobalModSettingsCategory   (GetCategory / CreateCategory / GetOrCreateCategory)
        └── IGlobalModSetting        (GetSetting / CreateSetting / GetOrCreateSetting)
```

```csharp
public interface IModGlobalSettings
{
    IGlobalModSettingsTab GetTab(string name);                            // null if unknown
    IGlobalModSettingsTab CreateTab(string name);                         // displayKey = name
    IGlobalModSettingsTab CreateTab(string name, string displayNameKey);
    IGlobalModSettingsTab GetOrCreateTab(string name);
    IGlobalModSettingsTab GetOrCreateTab(string name, string displayNameKey);
    List<IGlobalModSettingsTab> GetTabs();
    List<IGlobalModSetting> GetAllGlobalSettings();                       // every setting in every tab
    void BindSettingsClass(Type settingsType);                            // see C# Setting Listeners
    void SaveSettings();                                                  // write the saved settings file now
}

public interface IGlobalModSettingsTab
{
    string Name { get; }
    string DisplayKey { get; }
    string TooltipKey { get; set; }
    IGlobalModSettingsCategory GetCategory(string categoryName);
    IGlobalModSettingsCategory CreateCategory(string categoryName, string displayName);
    IGlobalModSettingsCategory GetOrCreateCategory(string categoryName, string displayName);
    bool AddCategory(IGlobalModSettingsCategory category);
    bool RemoveCategory(string categoryName);
    bool RemoveCategory(IGlobalModSettingsCategory category);
    List<IGlobalModSettingsCategory> GetAllCategories();
    List<IGlobalModSetting> GetAllModSettings();
    bool HasToolTip();
    string GetToolTipText();
    string GetDisplayName();
}

public interface IGlobalModSettingsCategory : IGlobalModSetting
{
    IGlobalModSetting GetSetting(string name);
    T GetSetting<T>(string name) where T : class, IGlobalModSetting;          // null if not that type
    T CreateSetting<T>(string name, string displayKey) where T : class, IGlobalModSetting;
    T GetOrCreateSetting<T>(string name, string displayName) where T : class, IGlobalModSetting;
    bool AddSetting(IGlobalModSetting setting);
    bool RemoveSetting(string settingName);
    bool RemoveSetting(IGlobalModSetting setting);
    List<IGlobalModSetting> GetAllSettings();
}
```

Two things to know:

<Callout type="warn">
  **`CreateTab` throws `ArgumentException` if the name already exists.** When your XML may also
  declare the tab, use `GetOrCreateTab`. The same applies to categories and settings.
</Callout>

- **A category is itself an `IGlobalModSetting`.** That is how it gets a caption, description and
  preview image. Its `RestartScope` always reads `None`, and `GetAllSettings()` on a category
  returns the category first, followed by its settings.

## Creating settings from code

`CreateSetting<T>` takes one of the closed setting interfaces:

| Interface | Value types that work |
|---|---|
| [`ISelectorGlobalSetting<T>`](/docs/reference/global/i-selector-global-setting) | `int`, `float`, `string`, any enum |
| [`ISliderGlobalSetting<T>`](/docs/reference/global/i-slider-global-setting) | `int`, `float` |
| [`ISwitchGlobalSetting<T>`](/docs/reference/global/i-switch-global-setting) | `bool`, `string`, any enum |
| [`IColorSelectorGlobalSetting`](/docs/reference/global/i-color-selector-global-setting) | fixed, `UnityEngine.Color` |
| [`IControlBindingSetting`](/docs/reference/global/i-control-binding-setting) | fixed, no value |

```csharp
public void InitMod(IGearsMod mod)
{
    IGlobalModSettingsTab tab = mod.GlobalSettings.GetOrCreateTab("General", "myModTabGeneral");
    IGlobalModSettingsCategory display = tab.GetOrCreateCategory("Display", "myModCatDisplay");

    ISliderGlobalSetting<int> fov = display.GetOrCreateSetting<ISliderGlobalSetting<int>>("Fov", "myModFov");
    fov.SetAllowedValues(increment: 5, min: 45, max: 120);
    fov.DefaultValue = 65;
    fov.SettingValue = 65;
    fov.SelectedValue = 65;
    fov.UiFormatter = "0";
    fov.DescriptionKey = "myModFovDesc";
    fov.RestartScope = SettingRestartScope.None;
}
```

Always set `DefaultValue`, `SettingValue` and `SelectedValue` on a setting you create; a fresh
setting holds `default(T)` for all three. Settings created in `InitMod` are merged with whatever
`ModSettings.xml` declares under the same names, and the player's saved value is restored on top.

Exceptions from `CreateSetting<T>`:

- `ArgumentException` when `T` is not one of the interfaces above (for example
  `IGlobalModSetting` itself).
- `InvalidOperationException` when the value type has no implementation for that family
  (`ISliderGlobalSetting<string>`, `ISelectorGlobalSetting<double>`) or no registered parser
  (`ISelectorGlobalSetting<TimeSpan>`). See [C# Custom Value Types](/docs/csharp/custom-value-types).

## Every setting: `IModSetting`

```csharp
public interface IModSetting
{
    string Name { get; }
    string DisplayKey { get; }
    string CaptionKey { get; set; }
    string DescriptionKey { get; set; }
    bool Enabled { get; set; }        // greys the row out when false
    bool IsChanged { get; }           // SelectedValue differs from SettingValue
    bool IsDefault { get; }           // SettingValue equals DefaultValue

    event OnSettingEnabledEvent OnEnabled;            // raised when Enabled flips

    string GetDisplayName();          // Localization.Get(DisplayKey), falling back to Name
    bool HasCaption();
    string GetCaptionText();          // falls back to the display name
    bool HasDescription();
    string GetDescriptionText();
    bool HasPreviews();
    string GetCurrentPreview();       // the image for the selected value, or the setting's own image
    void AddPreview(string path);     // the setting's own image

    void ResetToDefault();            // SelectedValue = DefaultValue   (SettingValue untouched)
    void DiscardCurrentChange();      // SelectedValue = SettingValue
    void ApplyCurrentChange();        // SettingValue = SelectedValue; raises OnValueChanged / OnSettingChanged
}
```

And for every global setting:

```csharp
public interface IGlobalModSetting : IModSetting
{
    SettingRestartScope RestartScope { get; set; }   // None, Reload, Restart
    event OnSettingChangedEvent OnSettingChanged;    // raised by ApplyCurrentChange
    IGlobalModSettingsCategory Category { get; }
    IGlobalModSettingsTab Tab { get; }
}

public delegate void OnSettingChangedEvent(IGlobalModSetting setting);
```

## The three values

Every value setting holds three values of its type `T`:

| Property | Meaning | Changed by |
|---|---|---|
| `DefaultValue` | what `Reset` goes back to | `defaultValue` in XML, or you |
| `SettingValue` | the **applied** value: saved to disk, read by `modsetting()`, what your mod should act on | the player pressing Save (or Apply), the saved-settings restore, or you |
| `SelectedValue` | what the player currently has picked in the UI, possibly not yet applied | the UI, `ResetToDefault`, `DiscardCurrentChange`, or you |

```csharp
public interface IValueModSetting<T> : IValueModSettingBase
{
    event ValueSelectedEvent<T> OnSelected;    // SelectedValue changed
    T SettingValue { get; set; }
    T DefaultValue { get; set; }
    T SelectedValue { get; set; }
    string GetPreview(T value);
    void AddPreview(T value, string path);    // image shown while that value is selected; first one per value wins
}

public interface IGlobalValueSetting<T> : IGlobalModSetting, IValueModSetting<T>
{
    event ValueChangedEvent<T> OnValueChanged;   // SettingValue changed
}

public delegate void ValueSelectedEvent<T>(IValueModSetting<T> setting, T newSelectedValue);
public delegate void ValueChangedEvent<T>(IValueModSetting<T> setting, T newSelectedValue);
```

Read `SettingValue` when you want the value the player has committed to. Subscribe to
`OnValueChanged` to react when that changes. `OnSelected` fires on every click in the menu, before
the player has saved; use it for live previews only.

<Callout>
  Every setter is a no-op when the new value equals the old one, so the events fire only on real
  changes.
</Callout>

### String access

For code that works with settings generically:

```csharp
public interface IValueModSettingBase : IModSetting
{
    void SetSettingValueFromString(string raw);     // parse with the type's parser; unparseable → logged, value kept
    void SetDefaultValueFromString(string raw);
    void SetSelectedValueFromString(string raw);
    string GetUiFormattedSettingValue();            // as the player sees it (formatter, prefix, localized)
    string GetFormattedSelectedValue();
    string GetSerializedFormattedSettingValue();    // as saved to disk and returned by modsetting()
}
```

## Selector

```csharp
public interface ISelectorSettingBase : IValueModSettingBase
{
    string UiFormatter { get; set; }             // .NET format string for display (numbers only)
    string SerializationFormatter { get; set; }  // .NET format string for the saved value
    string LocalizationPrefix { get; set; }      // prepended to each value before Localization.Get
    bool Wrap { get; set; }
    string[] GetAllowedValuesDisplay();          // the values as the player sees them, same order as GetAllowedValues
    void SelectByIndex(int index);               // ArgumentOutOfRangeException outside the allowed values
}

public interface ISelectorGlobalSetting<T> : IGlobalValueSetting<T>, ISelectorSettingBase
{
    void SetAllowedValues(T[] values);
    void SetAllowedValues(T increment, T min, T max);   // int and float only; others log and ignore
    T[] GetAllowedValues();
}
```

The display strings are built when first asked for, so a formatter or prefix assigned after the
values still applies. `SetAllowedValues(increment, min, max)` requires `increment > 0` and
`min <= max`; otherwise it logs and leaves the values alone. An enum selector starts with every
declared member.

## Slider

```csharp
public interface ISliderSettingBase : IValueModSettingBase

    string SerializationFormatter { get; set; }
}

public interface ISliderGlobalSetting<T> : IGlobalValueSetting<T>, ISliderSettingBase where T : struct
{
    T Increment { get; }
    T Min { get; }
    T Max { get; }
    void SetAllowedValues(T increment, T min, T max);
}
```

Only `int` and `float` sliders exist.

## Switch

```csharp
public interface ISwitchSettingBase : IValueModSettingBase
{
    string LocalizationPrefix { get; set; }
    string GetRightText();                     // localized text of the right value
    string GetLeftText();
    void SelectButton(SelectedButton button);  // SelectedValue = that side's value
    SelectedButton GetSelectedButton();        // Right when SelectedValue equals the right value (and not the left), else Left

    enum SelectedButton { Right = 0, Left = 1 }
}

public interface ISwitchGlobalSetting<T> : IGlobalValueSetting<T>, ISwitchSettingBase
{
    T LeftValue { get; set; }
    T RightValue { get; set; }
    void SetSwitchValues(T leftValue, T rightValue);
}
```

[`SelectedButton`](/docs/reference/base/i-switch-setting-base-selected-button) is nested inside
`ISwitchSettingBase`, so either write `ISwitchSettingBase.SelectedButton.Left` or add
`using static GearsAPI.Settings.Base.ISwitchSettingBase;`.
A `bool` switch is `false` on the left and `true` on the right; an enum switch takes the first
two declared members; a `string` switch has no sides until you call `SetSwitchValues`. The
formatter string is ignored on switches.

## Color

```csharp
public interface IColorSelectorGlobalSetting : IGlobalValueSetting<UnityEngine.Color> { }
```

Everything comes from `IGlobalValueSetting<Color>`. Serialized as `R,G,B` in 0–255. Only the
setting-wide preview image is shown; per-value previews are ignored.

## Key binding

```csharp
public interface IControlBindingSetting : IGlobalModSetting
{
    InControl.PlayerAction PlayerAction { get; set; }
    void ClearBinding();
}
```

Not a value setting. Declaring a `<Binding>` in XML or creating one in code gives the player a
row to rebind; you attach the game `PlayerAction` it controls:

```csharp
IControlBindingSetting boost = category.GetSetting<IControlBindingSetting>("Boost");
if (boost != null)
{
    boost.PlayerAction = myPlayerActionSet.Boost;
}
```

Gears does not persist bindings in its saved settings file; the binding lives with the
`PlayerAction` set it belongs to.

## Restart scope

```csharp
public enum SettingRestartScope { None, Reload, Restart }
```

Set [`RestartScope`](/docs/reference/settings/setting-restart-scope) on a global setting to show
the player that a change needs a world reload or a game restart. Gears only shows the warning;
applying the value is still up to your code.

## Saving

Gears writes the player-level saved settings file when the player presses Apply in the Mods
window and at startup. Call `IModGlobalSettings.SaveSettings()` (or `IGearsMod.SaveSettings()`)
to write it at any other time, for example after changing a `SettingValue` from code. The file is
`<user data folder>\Gears\ModSettings.xml`, shared by all mods; you never need to edit it.
