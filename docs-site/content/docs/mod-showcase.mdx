---
title: Join the Mod Showcase
description: Open a pull request on the Gears GitHub repository to add your mod's card to the Mod Showcase page.
---

To list your mod on the [Mod Showcase](https://s7092910.github.io/Gears/showcase/) page, open a pull
request on the [Gears GitHub repository](https://github.com/s7092910/Gears). A pull request is a
proposed change that the Gears maintainer reviews before merging it into the site.

The page lists mods that use Gears for their settings. Each card shows the mod's name, a short
description, and an image, and links to the mod's page. A card also shows whether the mod has
global settings, which players can change from the main menu or in game, and world settings, which
are set for each world and can't change while the world runs. For more on both, see
[Global and World Settings](/docs/global-and-world-settings).

## Before you start

You need:

- A [GitHub](https://github.com/) account.
- [Git](https://git-scm.com/) installed.
- An image of your mod, such as its settings page in the Mods menu, at a 16:9 ratio. The card shows
  any other shape whole but smaller, with empty space at the sides or at the top and bottom.
- The URL the card should open, such as your mod's Nexus Mods or GitHub page.

To preview the page on your own computer before you submit it, you also need
[Node.js](https://nodejs.org/). Previewing is optional.

## Add your mod

<Steps>
<Step>
**Fork the repository.** On the [Gears repository](https://github.com/s7092910/Gears), select
**Fork**. GitHub makes a copy of the repository under your account.
</Step>
<Step>
**Clone your fork and create a branch.** Replace `<your-username>` with your GitHub username and
`my-mod` with your mod's name:

```bash
git clone https://github.com/<your-username>/Gears.git
cd Gears
git checkout -b mod-showcase/my-mod
```
</Step>
<Step>
**Add the image.** Save it in `docs-site/public/images/showcase/` as `<Mod-Name>.png`,
such as `My-Mod.png`. Keep the file size close to the images already there.
</Step>
<Step>
**Add the entry.** Open `docs-site/content/mod-showcase.ts` and add an entry to the end of the
`showcaseMods` list:

```ts
export const showcaseMods: ShowcaseMod[] = [
  // ...existing entries
  {
    name: 'My Mod',
    description: 'Adds a configurable loot multiplier, set from the Mods menu.',
    image: 'My-Mod.png',
    imageAlt: "My Mod's settings page in the Mods menu",
    url: 'https://www.nexusmods.com/7daystodie/mods/0000',
    globalSettings: true,
    worldSettings: false,
  },
];
```

| Field | What to put there |
| --- | --- |
| `name` | Your mod's name, shown as the card title. |
| `description` | One or two plain sentences that say what the mod does. |
| `image` | The image's file name from the previous step, such as `My-Mod.png`. Leave out the folder. |
| `imageAlt` | What someone should see in the image, for readers who can't see it. |
| `url` | The page the card opens. |
| `globalSettings` | `true` if your mod has global settings, otherwise `false`. |
| `worldSettings` | `true` if your mod has world settings, otherwise `false`. |

Cards appear in list order. The card shows a **Global settings** or **World settings** label for
each field set to `true`, and no label for a field set to `false`.
</Step>
<Step>
**Preview the page (optional).** From the `docs-site` folder, run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000/Gears/showcase/` and find your card. If the card shows a dashed box instead
of your image, check that the image is in `docs-site/public/images/showcase/` and that its file name
matches `image` exactly, including capital letters.
</Step>
<Step>
**Commit and push.**

```bash
git add docs-site/public/images/showcase/My-Mod.png docs-site/content/mod-showcase.ts
git commit -m "Add My Mod to the Mod Showcase"
git push -u origin mod-showcase/my-mod
```
</Step>
<Step>
**Open the pull request.** Open this URL in your browser, with `<your-username>` and the branch
name replaced by your own:

```text
https://github.com/s7092910/Gears/compare/main...<your-username>:Gears:mod-showcase/my-mod?quick_pull=1&template=mod-showcase.md
```

GitHub opens a new pull request from your branch to `main`, with the description already filled in
from the [pull request template](#pull-request-template). Title the pull request
`Add <Mod Name> to the Mod Showcase`, replace each placeholder in the description, then select
**Create pull request**.
</Step>
</Steps>

## Pull request template

The URL in the last step fills this in for you. If you opened the pull request another way, such
as with **Compare & pull request** on your fork, the description starts empty. Copy this into it
and replace each placeholder:

```md
## Mod Showcase request

**Mod name:** <Mod Name>

**Does it use Gears?** <Yes or No. If yes, say which features it uses, such as global settings,
world settings, or settings read from C#.>

**Description:** <One or two sentences on what the mod does.>

**Download page:** <URL of the mod's download page, such as its Nexus Mods page>
```

- `<Mod Name>` is the same value as `name` in your entry.
- The description can be longer than the one on the card. Use it to give the reviewer context.
- The download page is usually the same as `url` in your entry.

## After you submit

The maintainer reviews the pull request and may ask for changes in its comments. To make a change,
edit the files on the same branch, then commit and push again. The pull request updates on its own.

Your card appears on the Mod Showcase page once the pull request is merged and the site is
published.
